## 2. The spec

Three builders, disjoint files. Nobody edits a file outside their list; where a change needs a value from another chunk, it is written here so both sides can use it without talking. Every chunk ends with `npm run check` and `npm run build` green. World frame: x right, y up, z = plan y, +z the front of the house; the garden is z −5.6 … −12, x −4.5 … 5.8.

How to look (for every acceptance check): dev server `npx vite --port <n>`; Playwright from /opt/node22/lib/node_modules with `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader --ignore-gpu-blocklist`; click the first `.welcome-tile`, wait for `.dock`, then wait 6 s before the first camera request (an earlier one is dropped by the viewer's first-frame jump). Camera: `window.dispatchEvent(new CustomEvent('house:view', { detail: { pose: { position: {x,y,z}, target: {x,y,z} } } }))` — objects, not arrays — then wait 4 s; screenshots with `timeout: 180000, animations: "disabled"`. Store on `window.__houseStore`: `setMode('garden'|'furnish')`, `setUi({ tab: '3d', maxLevel, showCeilings })`, `setSun({ enabled, dayOfYear, hour })`, `updateSite(fn)`. The built-in garden has only seven items; add a test set with `updateSite(s => ({ ...s, items: [...s.items, ...] }))` (ids: `festoon-warm` with `to`, `playhouse-smoby-friends`, `mud-kitchen`, `lounge-corner`, `dining-4-round`, `bistro-2`, `bench`, `bollard`, `apple-tree`, `acer`-shaped trees, `hydrangea`, an allium and a grass from the Flowers and Grasses categories). Dusk: `setSun({ enabled: true, dayOfYear: 172, hour: <duskHour> })` (the sun panel's Dusk preset, `lib/dusk.ts` duskHour).

Replace `ico0` (used for parts under 0.25 m) with `SphereGeometry(0.5, 8, 6)`, smooth. `cone` → 12 radial segments. Acceptance: retake plants-trees, plants-row-small, plants-small-close-left: no visible triangle facets on canopies, mounds or flower heads; outlines still slightly irregular, not perfect spheres.
2. **Festoon light pools and a dusk that reads** (findings 1, 2, 22). `SiteItems.tsx` `festoon()`: push a pool for every second bulb onto `pools` at the ground under it (`sink.ground`), radius 0.9 m (`festoon-warm`: 1.0 m), y = ground + 0.012; pass `pools` into `festoon` the way `bulbs` is passed. Acceptance: structures-dusk and garden-patio-dusk retaken at the Dusk preset: warm pools visible on the patio along the line of the string; shaded walls and paving distinguishable (mean luminance of the patio region ≥ 35/255); ext-rear-dusk: rear render no brighter than in ext-rear and visibly cooler in shade.

### Ariana Grande: surfaces and textures

Owns `src/three/siteTextures.ts`, `src/three/textures.ts`, `src/three/wallTextures.ts`, `src/three/Site.tsx` (surfaces, kerbs, walls), `src/lib/floorFinish.ts` and `src/lib/floorPattern.ts` if needed, `src/lib/gardenCatalogue.ts` `KERBS` only, `src/editor/AddItem.tsx` thumbnails, `src/editor/site/SiteLayers.tsx` surface fills.

1. **Kerb top joints square, not chevrons** (finding 11). The kerb band top in `Site.tsx` `kerbBand()` maps a trapezoid (outer edge `a–b`, mitred inner edge `ai–bi`) to the same `u0..u1` on both edges, so the texture shears across each quad's diagonal and joints zig-zag. Give each top vertex u by projecting onto the segment: `dir = (b − a)/len`; `u(a) = u0`, `u(b) = u1`, `u(ai) = u0 + dot(ai − a, dir)`, `u(bi) = u0 + dot(bi − a, dir)`; v stays 0 at the outer edge and `width` at the inner. Same rule for the inner face. Then the kerb material: in `kerbMaterial()` use a `"brick-top"` texture kind for the brick band (new case in `siteTextures.ts`: 215 × 102.5 mm bricks laid along the edge with 10 mm joints `#8a7f6e`, same brick colours as `brick` but lightness −4, plus `speckle`), so the top doesn't flash white. `KERBS.brick.height` 0 → 0.02 so a flush brick edge casts a thin shadow line. Acceptance: bed-close, lawn-close retaken: joints run straight across the kerb at right angles to its edge, no chevrons; joint colour reads mid-grey-brown, not white.
2. **Raised bed coping** (finding 12). For a raised surface (`slope.base > 0`) with a brick kerb, build the band as a brick-on-edge coping: `up` 0.065, overhanging the outer face by 0.015 (offset the outer edge outwards by 0.015, which `insetOutline` can do with a negative width step), in the `brick-top` texture with joints every 0.075 m (headers across). Acceptance: patio-close, roundbed-close retaken: a distinct coping course with a shadow line under its lip caps the raised bed wall.
3. **Lawn** (finding 13). `siteTextures.ts` `case "lawn"`: base `hsl(95, 26, 31)`; 16 000 blade strokes, length 3–7 px, hue 70–115, saturation 20–42, lightness 22–48, alpha 0.6; stripes 0.05 alpha on alternate 0.5 m bands (one stripe per tile half); a few (8) faint brown-yellow patches `rgba(150,140,80,0.06)` 30–80 px.
